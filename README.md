A single Wi-Fi network name that tells a whole story in 28 characters: **SheLeftMeForTheITGuyNextDoor**. A husband whose wife left him for the IT guy next door broadcasts the betrayal as his network name — a name the IT guy next door sees every time he opens his phone's network list. The medium is part of the punchline.

`main.py` is a deterministic Python program with no network access. It writes exactly that name (28 characters, no trailing newline) to `/output/entry.txt`, validating the 1–32 character gate and verifying the written file round-trips byte-for-byte before exiting.

## Run it

```sh
python3 main.py
```

Set `OUTPUT_DIR` to write `entry.txt` somewhere else (for example `OUTPUT_DIR=/tmp/out python3 main.py`).
